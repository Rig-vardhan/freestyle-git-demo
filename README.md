\#Jenkins CI/CD Automation Assignment

This assignment demonstrates Jenkins CI/CD automation using Freestyle and Pipeline projects integrated with GitHub. The project automates build execution whenever code changes are pushed to the Git repository branch `b1`.



\## Key Tasks Performed



\- Created a Freestyle Jenkins job named `freestyle-git-demo`

\- Configured Git SCM with GitHub repository integration

\- Enabled Poll SCM trigger for automatic build detection

\- Configured automatic polling every 2 minutes

\- Added build steps using shell/batch commands

\- Verified SCM-triggered automatic builds in Jenkins



\- Created a `Jenkinsfile` for Pipeline automation

\- Implemented Pipeline stages:

&#x20; - Checkout

&#x20; - Build

&#x20; - Test

&#x20; - Deploy



\- Created a Pipeline Jenkins job named `pipeline-demo`

\- Configured Pipeline Script from SCM

\- Connected Pipeline job with GitHub repository and branch `b1`

\- Verified automatic Pipeline execution after code changes

\- Successfully monitored stage-wise execution using Jenkins Stage View



\## Technologies Used



\- Jenkins

\- Git

\- GitHub

\- Jenkins Pipeline

\- CI/CD Automation



\## Outcome



Successfully implemented CI/CD automation using Jenkins with GitHub integration and automatic SCM-based build triggering.
